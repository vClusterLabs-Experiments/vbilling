vBilling {{ .Chart.AppVersion }} is metering tenant clusters in region "{{ .Values.region }}".
Destinations: {{ include "vbilling.adapters" . }}

Every endpoint except /healthz and /readyz needs the API token (the dashboard asks for it).
{{- if .Values.api.token }}
It is api.token.
{{- else if .Values.api.existingSecret }}
It is key api-token of Secret {{ .Values.api.existingSecret }}.
{{- else }}
The chart generated one; upgrades keep it.
{{- end }}

  export VBILLING_TOKEN=$(kubectl -n {{ .Release.Namespace }} get secret {{ include "vbilling.apiTokenSecret" . }} -o jsonpath='{.data.api-token}' | base64 -d)
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "vbilling.fullname" . }} {{ .Values.api.service.port }}
  curl -s -H "Authorization: Bearer $VBILLING_TOKEN" localhost:{{ .Values.api.service.port }}/api/v1/status      # destinations, lag, last window
  curl -s -H "Authorization: Bearer $VBILLING_TOKEN" "localhost:{{ .Values.api.service.port }}/api/v1/usage?group_by=tenant,sku"
  curl -s -H "Authorization: Bearer $VBILLING_TOKEN" localhost:{{ .Values.api.service.port }}/api/v1/reconcile   # ledger vs billing platform, previous UTC day
  open http://localhost:{{ .Values.api.service.port }}/                   # usage dashboard

Gateways send usage (POST /api/v1/events and /api/v1/records) with the ingest token, never the API token.
{{- if .Values.api.ingestToken }}
It is api.ingestToken.
{{- else if .Values.api.existingSecret }}
It is key ingest-token of Secret {{ .Values.api.existingSecret }}; without that key, vBilling generates one in its data volume (DATA_DIR/ingest-token).
{{- else }}
The chart generated one; upgrades keep it.
{{- end }}
{{- if not .Values.api.existingSecret }}

  kubectl -n {{ .Release.Namespace }} get secret {{ include "vbilling.fullname" . }} -o jsonpath='{.data.ingest-token}' | base64 -d
{{- end }}
{{- if .Values.api.tenantIngestTokens }}
A gateway that serves one tenant uses that tenant's token from api.tenantIngestTokens instead.
{{- end }}

Keep the dashboard and the API on an operator network, and never hand the API token to a tenant.
See https://vclusterlabs-experiments.github.io/vbilling/security.html
{{- if not .Values.persistence.enabled }}

WARNING: persistence is disabled. The ledger is the durable outbox for usage that
has not reached your billing platform yet; without a volume it is lost on restart.
{{- end }}
